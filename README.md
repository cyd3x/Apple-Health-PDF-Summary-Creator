A simple python script to generate a PDF summary of Apple Health data based on the export.xml file.

This is a work in progress script to generate a customizable PDF summary of Apple Health data, useful when sharing potentially useful data to healthcare providers.

Usage: 
python health_report.py /path/to/apple_health_export/export.xml -o my_report.pdf
